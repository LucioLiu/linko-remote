# 0.7.0 连接与面板改进

用户目标：两端分别安装软件后，输入验证码跨网连接；支持电脑改名和 SSH 入口。参考了 RustDesk 的本机信息/连接输入区、ToDesk 的设备码输入流程、AnyDesk 的设备标识与显示名称分离，以及 UU 的设备列表与连接入口。没有接入或依赖 UU 的远控 SDK。

## 已实现

- Mac 首页：本机名称、验证码卡片、设备列表、搜索、心跳状态、电脑改名、双击读取画面快照、复制针对当前设备的 AI 指令。
- Windows：可复用的接入包。首次输入 12 位验证码并确认授权，后续打开已安装面板；本机显示名可编辑。Mac 的备注名单独管理，不修改 Windows 系统计算机名。
- 验证码：10 分钟有效，刷新撤销未使用的旧码，一码绑定一个 Windows 密钥；相同密钥在有效期内可恢复同一加密回执。服务端只存 HMAC 派生值的摘要；请求有频率限制，验证码不进入 URL 或安装包。
- 跨网：通过已配置的 TLS 中继网关接入，保留证书指纹校验、独立设备身份、DPAPI 私钥保护和原动作去重机制。
- 中继监督：每 20 秒核验公网端口的 TLS 身份，连续 3 次失败后重启该转发子进程；不重新提交桌面动作。修复转发进程存活但公网链路停滞时一直等待的问题。
- SSH：保存主机/IP/SSH 别名、用户名和端口，改名、一键打开系统终端，沿用 OpenSSH 的密钥和主机校验。默认端口沿用 SSH 别名配置。不自动安装 SSH 服务，不承诺对无公网路由的 SSH 主机自动穿透。

## 使用

1. Mac 安装/打开邻控，在首页为目标 Windows 命名并生成验证码。
2. Windows 下载通用客户端，解压，双击「打开邻控.cmd」。
3. 点击 Mac 的「复制连接码」，粘贴到 Windows 并确认接入。专用客户端也支持手输 12 位数字。后续无需传回公钥或生成逐台邀请文件。
4. Mac 看到心跳后双击电脑读取真实画面，再使用 AI 操作。

这个版本的 Windows 安装包包含本控制端的公开网关地址和证书指纹，不含配对码或私钥。专用包可重复用于接入本控制端的多台电脑。公开通用包不含控制端地址或指纹，使用完整连接码带入公开连接参数；目前没有全局短设备码目录。新 Mac 首次仍需要配置可达中继。公共 bore 中继的容量和稳定性不由邻控保证。

## 验收边界

- Python 单元/集成测试已验证验证码兑换、同密钥恢复、过期、刷新、限流、安装包内容、改名不改变身份、SSH 参数验证，以及转发进程恢复逻辑。
- 所有 Windows PowerShell 文件通过 PowerShell 语法解析；Windows UI 和 Windows 原生功能仍需 Windows 实机验收。
- Mac 原生构建、签名校验与实际设备列表/搜索已核验。
- 真实公网地址已完成 TLS 指纹检查。只有在 Windows 从公网入口成功接入并取得实际桌面后，才算完整跨网验收。
- Windows 独立验收包使用临时账户数据目录，强制只读、不写登录启动或快捷方式，且关闭 LAN 发现与局域网回退，保证验收使用指定公网入口。原有配对不被覆盖。
