# 邻控文件传输

在「我的电脑」点已配对设备旁的「传文件」，或在「文件传输」中选择接收电脑。选好本机文件后点「请求发送」。接收端会显示发送电脑、文件名和大小，点「接收」后开始传输。完成后点「保存 / 下载」。macOS 应用打开系统保存面板，Windows 使用浏览器的下载设置。邻控只提供文件保存入口。

每份文件最多 100 MiB。两端可以同时发文件，任何一端都能取消传输。接收端校验完整文件后开放下载，临时副本保留约五分钟。取消、超时和校验失败会清理临时文件。发送时保持文件传输页面打开。

两个客户端和已配置的 TLS 中继都需要支持文件传输协议 v1。旧端继续使用现有配对和控屏功能。配对联系人才能发文件请求，每份仍要接收端单独确认，控屏授权不作为文件许可。

中继逐块传递文件，单份传输最多暂存一块，每块最多 512 KiB。中继会校验发送端提交的总长度与 SHA-256，接收端独立复核后才开放下载。中继重启会中断当前文件传输。客户端沿用原配对与中继证书指纹。

本地回归使用临时证书、真实 TLS 和两端应用的本地接口，覆盖双向并行传输、断开、取消和校验。运行 `python3 -m unittest discover -s tests -p test_file_transfer.py -v`。
