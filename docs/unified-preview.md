# 0.8 统一客户端预览

邻控使用同一套 HTML、CSS、JavaScript 和本地客户端引擎。Windows 与 macOS 均展示连接电脑、允许他人连接、编辑本机名称、SSH 和设置入口。

## 安装与旧版兼容

Windows 解压后运行「打开邻控.cmd」；macOS 使用「邻控统一预览.app」。两端均自带运行环境。

预览版 Windows 配置位于 `%LOCALAPPDATA%\LinkoRemote`，macOS 配置位于 `~/Library/Application Support/LinkoRemote`。0.7 的安装与配对保留在原客户端中，尚未自动迁移到新协议。连接双方均需安装统一预览版。

## 建立连接

1. 在接收连接的电脑开启允许连接，生成 10 分钟有效的 12 位连接码。
2. 在另一台电脑输入连接码。
3. 接收电脑核对申请者名称、设备号和系统，允许本次连接。
4. 发起电脑打开桌面，取得画面后操作。

反向操作需单独批准。新版服务上的长期授权持续有效，直到在设备列表撤销。程序重启后，重新打开接收开关即可继续使用原授权。Mac 接收连接需系统录屏和辅助功能授权；没有权限仍可主动连接 Windows。

## 传输与操作边界

预览服务使用独立的 HTTPS 中继并校验证书指纹。桌面会话只允许取屏和键鼠，不授予原版限定文件作业能力。每个操作使用唯一编号；回执丢失时只查询原结果，不自动重发输入。用户关闭接收连接后，本地工作进程检查停止标记。

当前为逐次截图和确认操作，尚非连续视频远程桌面。Mac 适配目前只处理主显示器。预览中继依赖测试主机和临时公网隧道，尚不能承诺生产可用性。SSH 调用系统终端和现有 SSH 配置，不代存密码。

## 0.8.1 更新检测与安装

设置页提供自动检查开关、手动检查、更新说明、下载进度和「安装并重启」。启动后约 8 秒自动检查，此后每 4 小时检查一次；检查与下载均在后台进行。安装只在用户选择后启动，有会话或未确认操作时阻止重启。

更新只读取本仓库的 GitHub Release，并按系统和架构选择安装包。HTTPS 重定向限定 GitHub 下载域名；SHA-256 必须与 GitHub 资产记录一致，安装前再次检查。ZIP 解压拒绝越界路径、符号链接、重名文件和超大内容。

Windows 按版本目录安装，保留上一版；macOS 在应用目录完成替换，并保留上一版应用包，替换失败恢复原包。新版启动后核对本地服务版本，失败时恢复或保留原启动入口。更新不会删除用户数据目录。Mac 被控权限仍需系统单独授权，更新程序不会自动开启。

旧 0.8.0 没有更新器，需手动安装本版一次。之后的版本可由软件内检测并更新。
