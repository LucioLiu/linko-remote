# 同一任务怎样选执行方式

一轮跨网对照使用 12 份合成 CSV，共 1,524 条输入。A 通过界面逐批操作；B 把同一批工作交给 Windows 本机处理。两种方式使用相同计算代码。表中计时均包含真实屏幕读回和导出文件逐行核验。

| 测试机 | A：逐批操作界面 | B：Windows 本机执行 |
|---|---:|---:|
| 设备一 | 56.9 秒 | 13.1 秒 |
| 设备二 | 65.1 秒 | 12.6 秒 |

四份成功产物逐字节一致，均含 78 项差异。应用层派发从每轮 8 次减到 2 次。设备二另有一次 B 请求在 80.9 秒后仍无法确认；后续检查没有找到该轮产物。把失败和成功两轮合计，实际用时至少 93.5 秒，另有排查时间。以上是两台设备的一次对照，不是跨地区的性能保证。

实际使用时，已有本地处理器的批量任务优先 B。遇到只提供界面的应用或必须看到业务结果的步骤，用 A 检查真实界面。收到超时先用同一请求 ID 查状态；对于申报、支付等不可重复的操作，还须读回业务系统里的最终记录。
